## Как будет проходить разработка итогового макета

Фишка нашего проекта заключается в том, что итоговый проект каждого студента будет уникальным. Мы научим вас пользоваться фигмой для сборки проекта и экспорта ассетов.
Для каждой секции сайта будет несколько прототипов на выбор  в фигме + галерея подходящих по стилю изображений. Контентную часть и палитру сайта по желанию тоже можно будет поменять.
